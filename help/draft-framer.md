# 権限設定

ラクミー経営管理クラウドを使うメンバーごとに、**どの画面を見られるか**を設定できます。経理担当・人事担当・アルバイトリーダーなど、貴社の体制に合わせた権限を自由に作成できます。

> このページは**オーナー・本部管理者の方向け**の説明です。権限の設定はこのお二方のみが行えます。一部の操作（すべての数字の確認、全権の委譲）はオーナーのみ行えます。
> はじめて設定される方は「導入時の初期設定」からお読みください。画面に出てくる言葉の意味は、ページの最後の「用語の説明」にまとめています。

**目次**

**共通項目**　権限設定でできること ／ ご利用の前提条件 ／ ご利用の流れ

**操作手順**

1. 導入時の初期設定　←　はじめて設定される方はここから
2. 権限を作成する
3. 権限をメンバーに割り当てる
4. 担当店舗を設定する
5. 表示する数字を選ぶ
6. 作成した権限を修正する
7. 権限を変更・解除する
8. オーナーだけができること
9. 設定内容を確認する

**ケース別のやり方**　経理担当 ／ 人事担当 ／ アルバイトリーダー ／ エリアマネージャー ／ 最小限から始める ／ 会社と店舗の両方

**よくあるご質問**　兼務する方の権限、設定を誤って画面が開けなくなったとき、役職との違い など

**用語の説明**　画面に出てくる言葉の意味（権限／区分／担当店舗／スコープ選択 など9語）。ページの最後にまとめています

## 権限設定でできること

貴社の体制に合わせて、メンバーごとに見える範囲を変えられます。

| こんなときに | 設定例 |
|---|---|
| 経理担当に売上や支払は見せたいが、従業員情報は見せたくない | 分析画面と支払を「閲覧」、従業員管理を「なし」 |
| 人事担当に従業員情報だけ見せたい | 従業員関連を「閲覧」、売上系を「なし」 |
| アルバイトリーダーに売上画面だけ見せたい | 売上分析を「閲覧」、それ以外を「なし」 |
| 新入社員にはまず最小限から始めたい | ダッシュボード以外を「なし」 |

> 今回のリリースで設定できるのは**画面を開けるかどうか**です。画面の中の一部の数字だけを隠したり、画面は開けるが変更だけを禁止したりする設定は、今回のリリースには含まれていません。

## ご利用の前提条件

**この画面で何ができるかは、ご自身の権限によって変わります。**

| | オーナー | 本部管理者 |
|---|---|---|
| 権限を作る・直す | できる | できる |
| メンバーに割り当てる | できる | できる |
| 担当店舗を設定する | できる | できる |
| 表示する数字を選ぶ | できる | できる |
| **すべての数字を確認する** | **できる** | できない |
| **全権を他の方に委ねる** | **できる** | できない |
| オーナーの権限を変更する | できない（全権で固定） | できない |

- 操作できるのは**オーナーと本部管理者**のみです。
- 権限を割り当てられるのは、**ラクミー経営管理クラウドにログインする方**です。従業員情報に登録されていても、ログインしない方は対象外です。
- **1人が持てる権限は1つ**です。別の権限を割り当てると、それまでの権限は自動的に外れます。
- 権限は**会社／店舗の区分**で分かれます。区分によって設定できる画面が変わります。

## ご利用の流れ

権限の設定は、次の3つの画面を行き来しながら進めます。

| 画面 | ここで何をするか |
|---|---|
| 権限設定 | 権限を作る・直す |
| ユーザー割当 | 権限をメンバーに割り当て、担当店舗を紐付ける |
| 権限一覧 | 誰が何の権限を持っているかを確認する |

> 権限設定とユーザー割当は、どちらからでも行き来できます。権限を作った直後にそのまま割り当てに進むことも、メンバーの設定中に権限そのものを直したり、新しい権限をその場で作ったりすることもできます。すでに割り当て済みの方には、その旨が一覧の行に表示されます。

## 導入時の初期設定

はじめて権限設定を開くと、**権限テンプレート**の画面が表示されます。よく使う権限をまとめて登録できます。

**流れ** — 権限テンプレート → 用意する権限を選ぶ → 初期値を選ぶ →「適用」→ **権限一覧**に登録される

登録できる権限は次の4つです。初期状態ではすべて選択されています。

| 権限 | 内容 |
|---|---|
| オーナー（全権） | すべての操作ができます（変更不可） |
| 会社ロール（権限母体） | 本部・全社向けの土台。経理・人事などはここから作ります |
| 店長（権限母体） | 店舗運営の土台。エリアマネージャーなどはここから作ります |
| 従業員 | 閲覧が中心です |

「適用」を選択すると**権限一覧**が開き、登録された権限が並びます。

【画像①：権限テンプレートの画面】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ① 番）

> 途中で中断できます。「一時保存」を選択すると選んだ内容が保存され、次に開いたときに続きから設定できます。最初からやり直す場合は「下書きを破棄」を選択すると初期状態に戻ります。


> まず土台を作り、あとで分けるのがおすすめです。導入時は「会社ロール（権限母体）」をひとつの土台として作り、運用が始まってから「経理」「人事」に分けていく進め方をおすすめしています。最初から細かく分けると、運用が固まる前に線引きを決めてしまうことになります。

## 権限を作成する

**流れ** — 権限設定 →「＋ 権限を新規作成」→ 雛形を選ぶ → 権限名と区分 → 画面ごとに設定 →「保存」→ **権限一覧**に戻る

### STEP 1　権限設定画面を開く

1. [ラクミー経営管理画面](https://manager.rakmy.jp/users/sign_in)にログインする
2. 画面上部のスコープ選択で、設定したい**会社または店舗**を選択する
3. 左側のメニューバーで「設定」＞「権限設定」を選択する

【画像②：権限設定の一覧画面】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ② 番）

> スコープによって表示が変わります。会社を選択すると会社向けの権限と画面が、店舗を選択すると店舗向けの権限と画面が表示されます。


### STEP 2　雛形を選ぶ

1. 「＋ 権限を新規作成」を選択する
2. 雛形（ベース）を選ぶ

近いものを選ぶと、あとの設定が少なくて済みます。

| 雛形 | 内容 |
|---|---|
| 本部管理 | 全社の設定・一覧を操作／閲覧できます |
| 店長 | 自店舗の設定・一覧を操作／閲覧できます |
| 従業員 | 閲覧が中心です |
| 既存の権限をコピー | 運用中の権限を複製して、一部だけ変更できます |
| 新規作成 | すべて「なし」の状態から設定します |

【画像③：雛形（ベース）の選択画面】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ③ 番）

> ゼロから設定する必要はありません。設定できる画面は27種類あります。近い雛形を選び、違うところだけ変更するのがおすすめです。
> たとえばエリアマネージャーは、雛形の一覧にはありませんが「店長」を選んで権限名を変え、担当店舗を複数紐付ければ作れます。組織によって中身が変わるため、雛形としては用意していません。


### STEP 3　権限名と区分を決める

1. **権限名**を入力します（例：経理担当、エリアマネージャー）。
2. **区分**を選ぶ

【図3：会社と店舗の区分】← ここに 図/03_会社と店舗の区分.png（または .svg）を挿入。**図は作成済み**

> 区分は先に決めてください。区分によって次の画面に表示される項目が変わります。あとから区分を変更すると、設定をやり直していただく場合があります。


> 会社と店舗の両方の画面を使う場合は、権限を2つ作ってください。1つの権限で会社画面と店舗画面の両方を扱うことはできません。たとえば経理の方が「お支払い（会社画面）」と「費用設定・予算設定（店舗画面）」の両方を見る場合、**「経理（会社）」と「経理（店舗）」の2つの権限を作り、担当を分けて割り当てます**。1人が持てる権限は1つのためです。


### STEP 4　画面ごとに設定して保存する

画面ごとに「操作」「閲覧」「なし」を選び、「保存」を選択します。保存すると**権限一覧**に戻ります。

| 設定 | できること |
|---|---|
| **操作** | 画面を開けて、登録・編集・削除ができます |
| **閲覧** | 画面を開けます |
| **なし** | 画面が表示されません |

> 「閲覧」と「操作」は、今回のリリースではどちらも**画面を開けるかどうか**の設定として動作します。「閲覧」を選んだ場合に画面内の変更操作を禁止する制御は、次回以降のリリースで対応予定です。変更させたくない方には、その画面を「なし」に設定してください。

「操作」は「閲覧」を含みます。「操作」を選ぶと「閲覧」も自動的に有効になります。

【画像④：画面ごとの設定（操作／閲覧／なし）】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ④ 番）

> さらに細かく設定することもできます。画面名を選択すると、その画面の中の機能や、表示する数字（指標）を個別に設定できます。


続けてメンバーに割り当てる場合は、「保存」ではなく「🔗 ユーザー割当で紐付け →」を選択します。

## 権限をメンバーに割り当てる

作成した権限は、メンバーに割り当てて初めて有効になります。割り当て方法は3つあり、目的に応じて使い分けます。**始める画面と、保存後に開く画面がそれぞれ違います。**

| 方法 | 始める画面 | 保存後に開く画面 |
|---|---|---|
| 方法1　まとめて割り当てる | 権限の設定画面 | 役割サマリ |
| 方法2　メンバーを選んで割り当てる | ユーザー割当 | ユーザー割当 |
| 方法3　権限から探して割り当てる | 役割サマリ | ユーザー割当（絞り込みは保たれます） |

「役割サマリ」は、権限ごとに何名へ割り当てているかを確認する画面です。

### 方法1　まとめて割り当てる（権限を作った直後におすすめ）

1. 権限の設定画面の下部で「🔗 ユーザー割当で紐付け →」を選択する
2. 割り当てる方の「含める」にチェックを入れる
3. 店舗の権限の場合は、あわせて担当店舗を選ぶ
4. 「保存」を選択する

保存すると**役割サマリ**が開き、割り当てた権限が強調表示されます。

【画像⑤：まとめて割り当てる画面】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ⑤ 番）

> すでに別の権限をお持ちの方については、1人が持てる権限が1つのため、行に「⚠ 既に『◯◯』を保持。含めると置き換わります」と表示されます。保存前にも確認画面が表示されます。すでにこの権限をお持ちの方には「✓ この権限で登録済み」と表示されます。


> 対象は自動で絞り込まれます。店舗の権限を割り当てるときは店舗所属の方、会社の権限を割り当てるときは本部所属の方が表示されます。全員から選びたい場合は「すべて表示」を選択してください。


### 方法2　メンバーを選んで割り当てる（入社・異動のとき）

1. 権限設定画面の上部で「ユーザー割当」を選択する
2. 対象の方の行で「割当を編集」を選択する
3. 権限を**1つ**選ぶ
4. 「保存」を選択する

保存すると**ユーザー割当**に戻ります。

【画像⑥：メンバーごとの割当編集画面】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ⑥ 番）

### 方法3　権限から探して割り当てる（保持者を確認したいとき）

1. 権限設定画面の上部で「役割サマリ」を選択する
2. 対象の権限の「割当へ →」を選択する
3. その権限をお持ちの方に絞り込まれた状態で**ユーザー割当**が開く
4. 対象の方の行で「割当を編集」→「保存」を選択する

絞り込みは保たれたままです。

## 担当店舗を設定する

**開く場所** — 権限設定画面の上部で「ユーザー割当」→ 対象の方の行で「割当を編集」

**どの店舗の数字を見せるかは、権限ではなく人ごとに決めます。** 同じ「店長」の権限でも、渋谷店の店長には渋谷店を、新宿店の店長には新宿店を設定します。

【図2：権限と担当店舗の関係】← ここに 図/02_権限と担当店舗.png（または .svg）を挿入。**図は作成済み**

店舗の権限（区分が「店舗」の権限）を割り当てると、担当店舗の選択欄が表示されます。

1. 割当編集の画面で、店舗の権限を選択する
2. 「対象店舗」で担当店舗を選ぶ
3. すべての店舗を選ぶ場合は「全店」にチェックを入れる
4. 「保存」を選択する

担当店舗は複数選択できます。保存すると**ユーザー割当**に戻ります。

【画像⑦：担当店舗の選択画面】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ⑦ 番）

> 担当店舗は必ず1つ以上お選びください。店舗の権限で担当店舗が未設定の場合、保存できません。また、権限の設定画面に「⚠ ◯名が店舗未設定」と表示されます。


会社の権限は全社が対象となるため、担当店舗の設定は不要です。

> 今回のリリースでは、担当店舗は**割り当ての記録**として保存されます。担当外の店舗のデータを画面に出さない制御は、次回以降のリリースで対応予定です。

**ここまでで初期設定は完了です。** 以降は、見せる数字をさらに絞りたいとき、権限を直したいとき、異動・退職で付け替えたいときにお読みください。

## 表示する数字を選ぶ

同じ画面でも、表示する数字（指標）を権限ごとに選べます。

**流れ** — 権限一覧 →「指標一覧」→ 店舗／会社のタブを切り替えて選ぶ → **その場で反映（保存ボタンはありません）**

> 今回のリリースでは、この設定は**指標一覧の画面での選択状態を保存する**ところまでです。選んだ内容が分析画面の表示に反映されるのは次回以降のリリースになります。

1. 権限設定の一覧で、対象の権限の「指標一覧」を選択する
2. 🏬店舗指標／🏢会社指標のタブを切り替える
3. 各項目を選択して、表示／非表示を切り替える

保存操作は不要で、その場で反映されます。

【画像⑧：指標一覧の画面】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ⑧ 番）

> 初期値は自動で設定されます。権限の性質に応じた初期値が設定済みです。現場でお使いいただく数字は表示、経営に関わる数字は非表示から始まります。設定後の変更は自由です。


**項目が多い場合は「指標条件設定」が便利です。** 「指標条件設定 ＞」から、おすすめの組み合わせ（現場スタッフ向け／店長向け／管理者・経理向け）を選んで一括設定できます。**この画面だけは「適用して指標一覧へ」を選ぶまで反映されません。**「キャンセル」を選ぶと、変更は破棄されて指標一覧に戻ります。

作った組み合わせは「名前をつけて保存」すると**マイテンプレート**に登録されます。他の権限を設定するときに読み込めるので、同じ組み合わせを作り直す必要はありません。保存した組み合わせは更新・削除もできます。

## 作成した権限を修正する

作成済みの権限は、いくつかの入口から修正できます。**どこから入っても同じ編集画面**が開き、**保存すると元いた画面に戻ります**。

| 入口 | 操作 | こんなときに |
|---|---|---|
| 権限一覧 | 対象の権限の行で「権限編集」 | 権限をまとめて見直したいとき |
| 権限一覧のマス目 | 権限×画面のマス目を選択 | 一覧で気づいた箇所をその場で直したいとき |
| 役割サマリ | 対象の権限の行で「権限編集」 | 全体を確認していて気づいたとき |
| 割当編集 | 権限の行で「権限編集 →」 | メンバーの設定中に権限そのものを直したいとき（割当編集の開き方は「権限をメンバーに割り当てる」で説明します） |

**権限名を変えるには** — 編集画面の上部にある基本情報で、権限名を書き換えて「基本情報を更新」を選択します。権限名を変えても、その権限を割り当てた方の設定はそのまま引き継がれます。

【画像⑨：マス目を選択して該当箇所へ移動したところ】← ここにスクリーンショットを挿入。**未取得**（撮影リスト ⑨ 番）

> 権限一覧のマス目を選択すると、その画面の設定箇所まで自動で移動し、一時的に色が付いて表示されます。27種類の画面から目的の項目を探す必要はありません。


> 権限の修正は、その権限をお持ちの**全員**に反映されますのでご注意ください。特定の方だけ変更したい場合は、権限を修正するのではなく、**既存の権限をコピーして新しい権限を作成**し、その方に割り当ててください。


メンバーの設定中に必要な権限が無いことに気づいた場合は、割当編集の画面から「＋ 権限を新規作成」を選ぶと、その場で権限を作れます。作成後は元の割当編集の画面に戻ります。

## 権限を変更・解除する

**開く場所** — 権限設定画面の上部で「ユーザー割当」→ 対象の方の行で「割当を編集」

異動や退職で、割り当て済みの権限を付け替える／外すときの操作です。

**別の権限に変更する**

割当編集の画面で、別の権限を選んで保存します。**それまでの権限は自動的に外れます。** 選択する前に、行に「選ぶと『◯◯』から置き換わります」と表示されます。保存すると**ユーザー割当**に戻ります。

**権限を外す**

割当編集の画面で「割当なし」を選んで保存します。担当店舗の選択欄も表示されなくなります。保存すると**ユーザー割当**に戻り、その方は「未割当」と表示されます。

> 権限を外した方は、ログインしても画面が表示されませんのでご注意ください。退職・異動の際は、権限を外すか、別の権限に付け替えてください。

## オーナーだけができること

全権をお持ちの方（オーナー）は、画面右上の「👑 オーナー操作」から次の2つを行えます。

| 操作 | 内容 |
|---|---|
| 指標管理 | すべての数字を一覧で確認できます（**確認のみ。変更はできません**） |
| 全権の付与先を指定 | 全権を委ねる相手を指名できます |

オーナーの権限は全権で固定されているため、権限設定の一覧には表示されません。設定を変更することもできません。

## 設定内容を確認する

設定が増えてきたら、一覧で確認できます。

**権限一覧** — 権限ごとに、どの画面をどこまで使えるかを一覧で見比べられます。「👤 表示ロール」で見たい権限だけに絞り込み、「📌 権限列設定」で見たい画面だけを表示できます。**選んだ表示は次に開いたときも保持されます。**

**役割サマリ** — 権限ごとに「割当ユーザー ◯名」を確認できます。店舗が未設定の方がいる場合は警告が表示されます。

## ケース別のやり方

### どのケースも共通の登録手順

権限の登録は、どのケースでも次の3つを順に行います。

1. **権限を作成する** — 雛形を選び、権限名と区分を決め、画面ごとに「操作／閲覧／なし」を設定して保存します。
2. **権限をメンバーに割り当てる** — 対象の方に、作った権限を付けます。1人が持てる権限は1つです。
3. **担当店舗を設定する** — 区分が「店舗」の場合のみ。どの店舗の数字を見せるかを、メンバーごとに選びます。

以下は、この3つのうち**ケースによって変わる部分だけ**をご案内します。

### ケース別の設定

**経理担当に、売上とお支払だけ見せたい**

区分は「会社」、雛形は「本部管理」を選びます。**従業員（閲覧）・従業員管理・ユーザー**を「なし」にすると、売上や仕入の数字とお支払いは見えて、従業員の情報は見えない状態になります。区分が「会社」なので、担当店舗の設定は不要です。

ただし**お支払いは会社の画面、費用設定・予算設定は店舗の画面**です。経理の方が両方を扱う場合は、「経理（会社）」と「経理（店舗）」の2つの権限を作り、担当を分けて割り当ててください。1人が持てる権限は1つのためです。

**人事担当に、従業員情報だけ見せたい**

区分は「会社」、雛形は「本部管理」を選びます。**売上分析・仕入分析・詳細分析・集計・お支払い**を「なし」にすると、従業員の情報と締め管理は見えて、経営の数字は見えない状態になります。担当店舗の設定は不要です。

**アルバイトリーダーに、一部の画面だけ見せたい**

区分は「店舗」、雛形は「店長」を選びます。**仕入分析・詳細分析・従業員（閲覧）・従業員管理・締め管理・費用設定・予算設定**を「なし」にすると、売上と日々の入力画面だけが残ります。所属する店舗を担当店舗に設定してください。

**複数の店舗をまとめて見せたい（エリアマネージャー）**

区分は「店舗」、雛形は「店長」を選びます。**画面の設定は変えずに**権限名を「エリアマネージャー」などに変え、**担当店舗で複数の店舗を選びます**。

エリアマネージャーは雛形の一覧にはありません。担当する店舗数や見せる範囲は組織によって変わるため、権限は「店長」と共通のものを使い、店舗はメンバーごとに設定する形にしています。

**新しく入った方には、まず最小限から始めたい**

区分は「店舗」、雛形は「まっさら（なし）」を選びます。**ダッシュボード以外をすべて「なし」**にすると、ログインしてダッシュボードだけが見える状態になります。慣れてきたら、必要な画面を1つずつ追加してください。

**会社と店舗の両方の画面を使わせたい**

1つの権限ではできません。区分ごとに権限を2つ作り、担当を分けて割り当ててください。1人が持てる権限は1つのためです。

> 画面の名前は区分によって変わります。会社の権限を作っているときに「費用設定」が見当たらないのは、それが店舗の画面のためです。どの画面がどちらに属するかは「権限を作成する」の STEP 3 にある図でご確認いただけます。

## よくあるご質問

権限の持ち方、見える範囲、設定を間違えたときの戻し方についてのご質問です。

**Q. 1人に複数の権限を割り当てられますか？**
A. できません。1人が持てる権限は1つです。「店長 兼 経理」のように兼務される方には、その方に合わせた権限を新しく作成してご利用ください。

**Q. 会社の画面と店舗の画面を1人で両方見られますか？**
A. 1つの権限ではできません。権限は会社／店舗のどちらかの区分に属し、1人が持てる権限は1つのためです。両方を見る必要がある場合は、区分ごとに権限を作り、担当を分けて割り当ててください（例：「経理（会社）」と「経理（店舗）」）。

**Q. 権限を変更すると、誰に影響しますか？**
A. その権限をお持ちの**全員**に反映されます。特定の方だけ変更したい場合は、既存の権限をコピーして新しい権限を作成し、その方に割り当ててください。

**Q. 設定した権限はいつから反映されますか？**
A. 保存後に反映されます。対象の方がログイン中の場合は、画面を移動された時点から反映されます。

**Q. 権限を絞りすぎて、何も見えなくなりませんか？**
A. ダッシュボードは常に表示されます。すべての画面を「なし」にしても、ログインしてダッシュボードに着地します。

**Q. 同じ権限で、人によって担当店舗を変えられますか？**
A. できます。権限は共通のものを使い、担当店舗をメンバーごとに設定してください。同じ権限でも、Aさんは2店舗、Bさんは3店舗という割り当てが可能です。ただし今回のリリースでは、担当店舗は割り当ての記録として保存されるところまでで、担当外の店舗のデータを画面に出さない制御は次回以降のリリースで対応予定です。

**Q. 画面は見せたいが、変更はさせたくない場合はどうすればよいですか？**
A. 今回のリリースでは、その設定はできません。「閲覧」を選んでも画面内の変更操作は制限されないためです。変更させたくない場合は、その画面を「なし」に設定してください。変更のみを禁止する制御は次回以降のリリースで対応予定です。

**Q. 役職を変更すると権限も変わりますか？**
A. 変わりません。役職は従業員情報の肩書きで、権限とは別のものです。権限を変更する場合は「ユーザー割当」から操作してください。

**Q. 自分の権限を変更できますか？**
A. 権限設定の画面を開けなくなる変更はできません。誤ってご自身を締め出さないよう、警告が表示されます。

**Q. 作った指標の組み合わせを、他の権限にも使えますか？**
A. できます。「指標条件設定」で作った組み合わせを「名前をつけて保存」すると、マイテンプレートに登録され、他の権限を設定するときに読み込めます。

**Q. 権限が未設定の方はどうなりますか？**
A. ログインしても画面が表示されません。「ユーザー割当」で未割当の方がいないかご確認ください。

**Q. 新しい画面が追加された場合、権限はどうなりますか？**
A. すべての権限で「なし」の状態で追加されます。ご利用になる場合は、権限設定から個別に許可してください。

## 用語の説明

画面に出てくる言葉の意味です。読んでいて分からない言葉が出たときにご覧ください。

| 用語 | 意味 |
|---|---|
| **権限** | 「どの画面をどこまで使えるか」を決めたもの。名前を付けて保存します |
| **区分** | その権限が会社画面向けか店舗画面向けか。会社／店舗のどちらかを選びます |
| **担当店舗** | 店舗の権限を持つメンバーが、どの店舗を担当するか。**メンバーごと**に設定します |
| **スコープ選択** | 画面上部にある、会社と店舗を切り替える欄。ここで選んだ側の権限と画面が表示されます |
| **雛形（ベース）** | 権限を作るときの土台。近いものを選んで違うところだけ直します |
| **権限母体** | 経理・人事など複数の権限を派生させるための、共通の土台となる権限 |
| **権限一覧** | 作った権限を、画面ごとの設定とあわせて一覧で見比べる画面 |
| **役割サマリ** | 権限ごとに、何名に割り当てているかを確認する画面 |
| **指標** | 売上・原価・人件費など、画面に表示される数字のこと |


「役職」は従業員情報に登録された肩書きで、**権限とは別のもの**です。役職を変更しても権限は変わりません。
