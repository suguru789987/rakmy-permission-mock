## 掲載サイトの書き方（help.rakmy.jp の実ページで確認）

2026-08-05 に「ダッシュボード」「連携設定」の2ページを参照して確認した。

| 要素 | 実サイトの書き方 |
|---|---|
| H1 | 機能名のみ |
| 階層 | H2・H3。ページによって会社スコープ／店舗スコープでH2を分ける場合もある |
| 導入文 | 1〜2文。無いページもある |
| 注記 | **引用ブロック（`>`）** |
| 表 | 多用する（列名を明示） |
| 画像 | 必須ではない（ダッシュボードは画像なし） |
| 文体 | です・ます調。簡潔 |
| 手順 | 番号付きリスト。使わないページもある |
| 末尾 | **「サポートが必要ですか？」＋ サポートチームに連絡** |

**Framer版の注記を引用ブロックに統一した理由**：実サイトが引用表示のため。ジョブカンAPI連携ページの原稿では平文化していたが、掲載結果に合わせて揃えた。

## 執筆方針

顧客向けのため、社内用語と実装用語は使わない。

| 使わない | 使う |
|---|---|
| ロール | 権限 |
| ベーステンプレート | 雛形 |
| 指標カタログ | 表示する数字（指標） |
| スコープ／データ範囲 | 担当店舗 |
| カテゴリ／feature_key | 画面 |
| fail-closed | （書かない。「すべての権限でなしの状態で追加されます」と挙動で説明） |

段階導入（P0〜P5）には触れない。顧客にとっては「今使える機能」がすべてであり、今後の実装予定は掲載しない。

## 図（SVG／PNG）

`help/figures/` に格納。**ASCII図は Notion・Framer で崩れるため使用しない。**

| 図 | 掲載箇所 | ファイル |
|---|---|---|
| 図1 ご利用の流れ | ご利用の流れ | `01_ご利用の流れ.svg` / `.png` |
| 図2 権限と担当店舗の関係 | 用語の説明 | `02_権限と担当店舗.svg` / `.png` |
| 図3 会社と店舗の区分 | 権限を作成する STEP 3 | `03_会社と店舗の区分.svg` / `.png` |

- **SVG** — Notion・Framer ともに画像としてアップロードできる。拡大しても劣化しない
- **PNG** — SVG を受け付けない場合の予備（幅2000px・Retina相当）
- 原稿の `【図N：…】` は**すでに用意した図**の差し込み位置。`【画像①〜⑩】` は**未取得のスクリーンショット**で、別物として区別している
- 作り直しは `python3 help/figures.py` を実行後、Chrome のヘッドレスで PNG に変換する
